# 0.1.1 DSH CLI Release 设计

- 日期：2026-08-19
- 分发方式：发布已构建的 npm `.tgz`，由 DSH rc7 的 `dsh plugin` 命令交给 Profile 内 pnpm 安装。
- 默认 Profile：`web`；安装和卸载脚本均可通过 `-Profile` 覆盖。
- 安装流程：`install-release.ps1` 从脚本所在目录定位唯一 `.tgz`，然后执行 `dsh plugin --profile <profile> add <absolute-tgz-path>`。
- 卸载流程：`uninstall-release.ps1` 执行 `dsh plugin --profile <profile> remove dsh-sandbox-escalation-fix`。
- 发布流程：`build-release.ps1` 先执行 `npm run build`，再运行 `npm pack` 生成版本化 tarball，并将 tarball 和安装/卸载脚本复制到 `release/`。
- 安全边界：脚本不写入 DSH 源码，不手动改 Profile Patch，不安装嵌套 node_modules；实际 Profile 依赖与 Bundle 同步完全由 DSH CLI 负责。
