# 0.1.2 rc8 兼容设计

- 日期：2026-08-20
- 目标：在不改变沙箱 Schema 投影算法的前提下，将插件兼容范围扩展到 DSH `0.1.0-rc.8`。
- 依据：rc8 仍会在受限 Shell/FS 组合中静态公开 `sandbox_permissions` 与 `justification`，严格变宽仍在执行期校验；插件所解决的问题仍可能出现。
- 最小改动：扩展 peer dependency 上限、运行时版本白名单和版本测试；开发依赖统一切换到 rc8 做真实构建与集成测试。
- 文档边界：明确 rc8 已增加 `approval=never` 的自然语言提醒，属于部分改善；可靠性尚未明确，建议用户仅在 rc8 实际复现同类问题后安装本插件。
- 不变范围：不修改权限矩阵、同模式参数正规化、工具包装、结果过滤与 Agent 生命周期协调逻辑。
